📝 Code d'Exemple

Voici comment initialiser la navbar avec vos propres paramètres :

initBottomNavbar({ theme: 'light', // 'light' ou 'dark' style: 'floating', // 'default', 'floating', 'compact' alwaysVisible: false, // true pour afficher sur desktop autoHide: true, // masquer automatiquement au scroll customItems: [ { id: 'home', icon: '🏠', label: 'Accueil', href: '/', badge: null }, { id: 'custom', icon: '⭐', label: 'Custom', href: '#', badge: 5, onClick: () => console.log('Custom action!') } ], onItemClick: (item) => { console.log('Clicked:', item.label); } });

🎯 Fonctionnalités

  • ✅ Responsive Design - S'adapte automatiquement aux différentes tailles d'écran
  • ✅ Animations Fluides - Transitions CSS optimisées avec cubic-bezier
  • ✅ Badges Dynamiques - Système de notification en temps réel
  • ✅ Thèmes Personnalisables - Clair/sombre avec transitions
  • ✅ Auto-masquage - Se cache automatiquement au scroll vers le bas
  • ✅ Effet Ripple - Animation de clic moderne
  • ✅ SafeArea Support - Compatible avec les encoches d'iPhone
  • ✅ Accessibilité - Navigation au clavier et lecteurs d'écran
